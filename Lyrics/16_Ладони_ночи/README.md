# Альбом №16. «Ладони ночи»

Всё важное лежит дальше завтрашнего дня, а мы редко смотрим дальше.
Этот альбом о том, что не помещается в одну жизнь: о вечном, о сроке, об ушедших, о непонятном в самих себе.
В основе песен мои стихи конца прошлого века. Одни вошли почти без изменений, другие я переработал, третьи дописал только сейчас.
Исполнители вымышлены: он и она придуманы для этого альбома и живут только в его песнях. Любое сходство с реальными людьми случайно.
