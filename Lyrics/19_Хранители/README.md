# Альбом №19. «Хранители»

Этот альбом о героях книги «На грани мира», первой в цикле «Хранители миров».
Песни не пересказывают сюжет, а показывают героев с другой стороны: что они чувствуют, о чём думают и почему поступают так, а не иначе.
Каждая песня здесь отдельная законченная история, понятная и без книги.
